# hello-skillz

Example plugin for the skillz marketplace. Install it to confirm the marketplace is wired up, then use it as a reference when writing real plugins.

## Install

```
/plugin marketplace add BuildQube/Skillz
/plugin install hello-skillz@skillz
```

## What's inside

| Type | Name | Purpose |
|------|------|---------|
| Skill | `hello` | Responds to "is skillz installed?" style questions with what's available |
| Command | `/hello-skillz:hello` | Prints a greeting and lists the plugin's components |
